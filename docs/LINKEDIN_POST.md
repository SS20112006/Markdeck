Why do we still waste hours wrestling with slide layout boxes in PowerPoint or Keynote, when all we really want to do... is write Markdown?

Over the past few days, I built **Markdeck** — an open-source presentation engine engineered for developers, speakers, and teams who want to turn raw Markdown into fluid, Keynote-grade slide decks in seconds.

Here is what makes Markdeck different:

⚡ **Instant Split-View**: Type Markdown in CodeMirror on the left, watch your 16:9 presentation slide update synchronously on the right with zero lag.
📂 **Zero-Friction Import**: Drag and drop any existing `.md` file directly from your Mac or PC straight into the browser. Zero account creation, zero cloud lock-in.
🖥️ **Built for Live Talks**: Hit `⌘ + Enter` to enter an immersive, distraction-free fullscreen presentation mode with 60fps transitions powered by Framer Motion.
🎉 **Interactive Reactions**: Hit `C` on stage to trigger celebratory confetti for demo finales and milestone announcements.
📄 **Production Utilities**: Native 1-click PDF export (`⌘ + P`) with 1-slide-per-page landscape styling, speaker notes support, and automatic local storage persistence.
🎨 **Apple HIG Craftsmanship**: Designed with native optical typography (SF Pro Text vs SF Pro Display), subtle vibrancy materials, and dark mode support.

🛠️ Built with:
React 19 • Vite 8 • TypeScript • Tailwind CSS v4 • CodeMirror 6 • Framer Motion • CI/CD with GitHub Actions
